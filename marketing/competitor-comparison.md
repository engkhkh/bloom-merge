# Bloom Merge compared with similar merge games (Nov 2026)

Games compared: **Triple Town** (Spry Fox, the original merge game), **Merge Dragons!** and **Merge Magic!** (Gram Games/Zynga), **Merge Gardens** (Futureplay), **Merge Mansion** (Metacore).

| Feature | Others | Bloom Merge before | Bloom Merge now (v0.14) |
|---|---|---|---|
| Core merge | Triple Town: 3 in a line. Merge Dragons/Magic: 3 or 5 touching. Merge Mansion/Gardens: 2 by dragging | 2 by dragging | same |
| Bigger-merge bonus | Merge Dragons/Magic: a 5-merge gives a bonus item | none | **Combos:** 3 merges in a row = double points; every 5 in a row = +1 💧 |
| Wild card | Triple Town crystal matches anything | none | **💧 Magic Water:** grows any plant one size, free move |
| Obstacles | Triple Town bears, Merge Dragons dead land | rocks, ice | same |
| Orders / quests | Merge Mansion, Merge Gardens: order boards. Merge Dragons: secondary goals | level goals only | **Daily Quests:** 3 a day, same for everyone, rewards 💧 |
| Collection book | Merge Dragons Dragon Book, Merge Magic creatures | Garden Album (12 animals) | same |
| Decorate a home base | Merge Gardens/Mansion/Magic garden or house | My Garden | same |
| Seasonal events | All of them | 6 seasonal gardens | same |
| Two modes in one | Merge Gardens: merge + match-3 levels | levels + Daily + Family + Editor | same |
| Energy timers / paid currency | All of them; reviews complain about energy | none (by design) | **none (kept on purpose: family-friendly, no pressure)** |
| Ads / in-app purchases | All of them | none | none |
| Story / characters | Merge Gardens, Merge Mansion | none | not added (big content job; idea for later) |
| Cross-device sync | Merge Gardens via account | none | not added (would need accounts and personal data) |

## Deliberately not copied
- **Energy, timers and gem shops:** the main complaint in app-store reviews of these games, and against the promise in our privacy policy and store listing.
- **Accounts and leaderboards:** they would need personal data, which our privacy policy says we don't collect.
